# 听阅

在 Mac 本机把课程、会议、访谈及个人录音转成可搜索的文字，按连续发言阅读，点击句子即可回听。音频只引用原文件；语音转写与说话人区分均在本机执行。可选接入自己的大模型接口，通过听阅助手提问、整理和修订转写正文。

## 使用

1. 打开 `dist/听阅.app`。
2. 首次使用检查“模型设置”。本项目已下载模型时，应用会使用旁边的 `dist/Models`；也可选择任意模型目录，或在应用内下载/导入模型。
3. 导入 MP3、M4A、WAV、FLAC，或把文件拖入窗口。模型就绪后自动按队列处理。
4. 正文按连续发言显示：同一说话人的连续短句合成一个段落，换人或停顿超过 8 秒开始新段。点击段落中的具体句子回听，播放时高亮当前句。
5. 顶部搜索框支持当前音频和全部录音，也能找到跨越原始短句边界的关键词；点击结果定位到命中句子。
6. 右键句子可校对、回听或复制；段落右上角菜单可逐句校对整次发言。点段落上的说话人名称可纠正整段归属，“说话人”面板可统一改名或指定实际人数。
7. “排版”可调整正文大小，开启/关闭自动补标点和长发言换行；播放器右侧可设置回听提前量（0、0.5、1、2 秒），默认 1 秒。字号、标点与换行偏好、提前量、上次查看的音频和播放位置会保留。
8. “导出”可选择“纯对话 TXT（无时间范围）”，仅保留说话人和对话正文；也可导出带时间范围的发言文字 TXT，以及保留原始句子时间轴的 SRT。两种 TXT 都按发言分段，沿用当前阅读排版和校对内容。音频列表右键可重命名资料库记录。

快捷键：⌘G / ⇧⌘G 切换搜索结果、⌥⌘Z / ⇧⌥⌘Z 撤销或重做校对、⌘F 搜索、⇧⌘L 定位当前句、⌘＋/⌘－ 调整字号、⌘空格 播放/暂停、⌘←/⌘→ 后退/前进 10 秒。

说话人数默认自动估计；知道人数时可在处理前指定。跨说话人边界或未匹配到说话人的片段显示“待核对”。自动标签仅代表同份录音内的声音聚类，不自动判断面试官/候选人身份。

原音频被移动后，可通过播放器的“重新定位文件”选择原文件；程序校验内容相同后继续使用已有文字。移除资料库记录不会删除原音频。

重新转写创建新版本。如果旧版本有文字纠错、归属纠正或说话人改名，保留旧版本为当前版本；可在版本菜单切换。说话人区分失败时文字仍然可用，可单独重试。关闭窗口后应用可继续处理，退出应用后未完成的任务显示中断，需手动重试。

## 环境与本地数据

- 当前交付面向 Apple Silicon Mac，macOS 14 或更高版本。
- Whisper large-v3 模型约 3.1 GB；另有约 1 MB 的 Silero VAD 模型和两个本地说话人模型。首次下载需要网络，模型准备完成后可离线使用。
- 转写使用 whisper.cpp 1.9.5 / Metal；说话人区分使用 sherpa-onnx 1.13.8 / CPU；格式转换使用 FFmpeg。
- 默认数据位置：`~/Library/Application Support/InterviewAudio/`。SQLite 保存资料库、文字、说话人名称、核对状态、最近 50 次校对修改历史和播放位置，`settings.json` 保存模型目录和阅读偏好。
- `INTERVIEW_AUDIO_DATA_DIR` 可指定独立的数据目录，用于开发与验收。
- 应用管理仅本机可访问的业务服务，不会上传录音，不含账号、云端识别或遥测。使用听阅助手时，向自行配置的模型接口发送任务所需的文字、来源与要求；测试连接仅发送固定测试消息。

把应用单独移到其他位置后，可在模型设置中重新选择本项目 `Models` 目录；模型不必随应用复制。

从“面试音频”改名为“听阅”后沿用原应用标识和 `InterviewAudio` 数据目录，已有转写、纠错、说话人名称和模型路径继续可用。内部可执行文件名称保留用于兼容，用户界面与应用名称为“听阅”。

## 构建

本机需安装 Apple Command Line Tools、Python 3.12+ 和 CMake。项目不依赖第三方 Swift 包或完整 Xcode。

```sh
python3 Scripts/bootstrap.py
python3 Scripts/download_whisper.py
zsh Scripts/package.sh
```

`bootstrap.py` 下载固定版本工具到 `.runtime/`，构建启用 Metal 的 whisper.cpp，并准备 ARM64 FFmpeg / sherpa-onnx。`package.sh` 构建 Swift 程序，打包并进行本地 ad-hoc 签名；这是个人本机交付，不包含开发者证书或公证发布。

完整模型目录需要：

| 文件 | 用途 |
|---|---|
| `ggml-large-v3.bin` | Whisper large-v3 转写 |
| `ggml-silero-v6.2.0.bin` | 检测语音，过滤非语音片段 |
| `segmentation.onnx` | pyannote segmentation 3.0 |
| `3dspeaker.onnx` | 中文 ERes2Net 声纹模型 |
| `punctuation.int8.onnx`（可选） | 约 76 MB，本地中英混合智能标点 |

应用下载和导入模型时进行 SHA-256 校验；安装的模型必须与固定版本一致。第三方组件来源见 `THIRD_PARTY_NOTICES.md`。

识别不使用指令式提示语，避免模型在弱语音区域重复提示语。Whisper 的内置 VAD 保留到原音频的时间映射。说话人分段使用 50% 窗口重叠、自动聚类阈值 0.8；这些默认值经过官方中文四人样本验证，其他录音仍可手动指定人数和纠正标签。

## 验证

```sh
swift test --disable-sandbox --cache-path .build/cache
python3 Scripts/test_worker.py
```

准备好实际录音验收产物后，可选择运行本地实际样本检查：

```sh
INTERVIEW_ACTUAL_TEST_DIR="$PWD/TestArtifacts" swift test --disable-sandbox --cache-path .build/cache
```

该检查使用完整录音的说话人结果，以及开头、中段、结尾的转写摘录，验证原文件未变化、原音频时间位置、中文搜索和 TXT/SRT 导出。输出标题明确标注“非完整转写”，不把测试摘录当作整段转写交付。

核心测试覆盖中文单字/子串与字面符号搜索、毫秒时间戳、长音频偏移、SRT 输出、人工纠错保护、资料库恢复及文件内容校验。进程集成测试覆盖转换/识别顺序、转写检查点、说话人阶段失败，以及取消后停止子进程和清理临时文件。

实际录音测试产物保存在忽略版本控制的 `TestArtifacts/`。识别准确率和耗时取决于录音质量、术语、插话与设备负载；结果保留原稿并允许人工核对，不预设准确率。

## 阅读标点与长发言排版（1.1.1）

默认在没有标点的中文短句间补逗号、句号、问号；明确的列举会使用冒号与顿号。连续表达与常见技术词尽量连接，已有标点优先保留。较长发言可在同一说话人块中适当换行。标点依据短句边界、停顿和有限的文字规则生成，用于辅助阅读，必要时可右键校对。

“排版”菜单提供“自动补标点”和“长发言适当换行”开关。补标点是阅读排版，不会自动写入识别原稿；每个点击区域仍对应原句的开始时间。搜索可跨原短句及生成标点，复制与 TXT 导出使用当前阅读样式，SRT 保留原句文字和时间轴。

校对窗口预填正在阅读的句子；只有修改后保存才写入人工纠错。悬停句子显示回听时间，右键空白区域不会误选附近的句子。

## 核对与整理（1.2.0）

- **说话人整理**：点击“说话人”，勾选重复标签，再选择保留的目标人物，点击“合并所选”。目标名称保留，句子的文字和时间不变。试听按钮依次播放同一个人分布在录音前、中、后的最多三个句子样本，每次最多 8 秒。
- **待核对筛选**：工具栏可切换全部发言、待核对、已校对。待核对句子带橙色点线；保留同次发言的上下文。打开“批量选择”后，可以选择多次发言，统一归属或标记核对完成。
- **逐句校对**：右键打开校对窗口，支持循环回听、倍速、查看原稿、修改归属和“保存并下一句”。保存默认标记已核对，可取消勾选。单次句子保存的文字和核对状态一起撤销。关闭校对窗口结束循环并暂停。
- **修改历史**：工具栏箭头菜单或“编辑”菜单可撤销、重做文字修改、归属调整、说话人改名/合并和核对标记。每个转写版本保留最近 50 次操作，重启应用后仍有效；新的修改会清除该版本的重做分支。重新运行说话人区分会保留人工归属及已确认归属，清空该版本旧撤销记录，避免撤销覆盖新自动结果。文本编辑框自身的 ⌘Z 仍由系统处理，持久校对撤销使用 ⌥⌘Z。
- **搜索导航**：搜索结果包含前后文、说话人和时间。⌘G / ⇧⌘G 连续回听命中结果，“返回搜索前的位置”恢复当时查看的录音、阅读句子、播放位置及播放/暂停状态。
- **资料库**：按名称或导入时间、时长排序，按任务状态筛选，也可仅筛选音频名称。缺失原文件时显示原路径与重新定位入口。应用菜单“关于听阅”显示当前版本和快捷键。

## 智能标点与阅读密度（1.2.0）

“排版”里提供紧凑、适中、舒展三种阅读密度，只调整长发言内部换行。同一次发言仍显示一个说话人标题，每个句子保留自己的点击定位。

可选的 CT-Transformer INT8 标点模型由 sherpa-onnx 本地 CPU 运行，不上传录音或文字。当前这台 Mac 已准备好模型；其他机器可在模型设置中下载或导入 `punctuation.int8.onnx`。可选模型缺失时仍可正常转写，并使用规则标点。

智能标点以同次发言的完整文字作为上下文，结果只允许添加标点，程序会逐字核验；若改变词语，整个结果被拒绝并回退到规则标点。已有标点、包含人工文字校对的发言、纯英文发言和超长发言保守使用原有排版。模型移除的空格不会导致原文空格丢失。首次读取时在后台生成，按原文及归属分组缓存，修改文字或合并说话人后重新检查缓存。

自动标点不会写进识别原稿，不改变句子时间。关闭“智能标点”使用规则标点；关闭“自动补标点”查看原稿。阅读、复制、搜索上下文与 TXT 使用同一排版；SRT 继续使用真实片段文字和时间。模型仍可能误判问句或列举，不能代替人工校对。

本地评估与包含模型的回归：

```sh
python3 Scripts/evaluate_punctuation.py
INTERVIEW_ACTUAL_TEST_DIR="$PWD/TestArtifacts" INTERVIEW_PUNCTUATION_MODEL_DIR="$PWD/Models" swift test --disable-sandbox --cache-path .build/cache
```

可给评估脚本传入 `--events TestArtifacts/actual-middle-events.jsonl` 等本地识别事件文件。评估文件包含文字，保存在忽略 Git 的 `TestArtifacts/`，不要上传私密录音的验收产物。

## 通过听阅助手整理正文

1. 右上角齿轮菜单 → “大模型配置…”，填写接口地址、模型名称和 API Key，测试连接后保存。支持 OpenAI 兼容 `chat/completions` 接口，本机免认证接口可留空 API Key。
2. 转写完成后展开右侧“听阅助手”（⇧⌘A），选择当前资料，输入“请直接整理当前正文，去掉口语赘词、改善断句，保留技术细节和原意”。也可先选中发言并引用，只整理指定部分。
3. 整理结果直接应用到当前阅读正文，助手展示修改差异；通过“修改记录与撤销…”可撤销整次修改。识别原稿、原片段标识、说话人和音频时间轴继续保留，仍可点击句子回听。
4. 长正文沿用助手分块分析、全部完成后统一提交的流程；失败或版本冲突不会留下半份正文修改。按原片段修订，跨段重排或大幅重写应先明确要求及来源定位边界。
5. 只想获得摘要或建议时，可输入“总结这次面试的问题”或“只提供原文整理建议”；这些请求不修改正文。独立“AI 整理”入口、整理稿页面和生成流程已移除。旧稿保留在兼容数据中，历史引用仍可只读回看，不自动合入正文。

大模型配置直接保存到数据目录中的 `llm-settings.json`，含明文 API Key，文件权限为 `0600`，可手动编辑。密钥不进入正文、修改记录、模型错误或导出内容。使用 `INTERVIEW_AUDIO_DATA_DIR` 时，配置与资料保存在对应独立目录。旧配置中的 `chunkCharacters` 为兼容保留，助手自行管理资料分块。

```json
{
  "baseURL": "https://服务地址/v1",
  "model": "服务商提供的模型名称",
  "apiKey": "填写自己的密钥",
  "maxOutputTokens": 8192
}
```

模型修订仍需结合识别原稿和录音核对。可以在逐句校对窗口查看“识别原稿”，或在修改记录中查看前后差异并撤销。

当前使用原生 SwiftUI 应用，通过 `zsh Scripts/package.sh` 重新编译打包；退出并重开 `dist/听阅.app` 即可使用新版。资料库和配置位于应用包外，更新沿用现有数据。目前未接入在线自动更新。

`PACKAGE_EMBEDDINGS=0 zsh Scripts/package.sh` 缩减体积。后端运行时和原生扩展由打包脚本签名，

### 助手交互

- 顶部“听阅助手”或 `⌘⇧A` 展开/收起右侧助手，首次默认收起；开关和宽度会记住。可拖分隔线，也可在助手设置的“侧栏宽度”中选择。
- 输入框支持多行：`Enter` 发送，`Shift+Enter` 换行；中文输入法选词时不会发送。收起、切换会话和发送失败保留本次应用运行内的草稿。
- 回答随模型生成逐步显示，结束后校验并排版；来源、覆盖范围与修改撤销放在对应回答下。生成期间可停止并保留部分输出。
- 向上阅读会暂停滚动跟随，点击“回到最新”恢复。搜索结果与资料库共用左栏。
- 连续追问使用同会话最近六轮、最多16000字符的历史；省略内容会标记。历史只帮助理解指代，当前资料及本次指令仍决定来源与操作范围。
- 接口明确不支持流式时显示等待完整回答的提示；已输出后遇到失败不会自动重新执行工具。
